## 💫 Floorp プロジェクトとは？

**「Floorp は、柔軟性、プライバシー、ウェブの公開性のバランスを追求するブラウザーです。」**

Firefox をベースとして、高度なカスタマイズ性と多数の実験的な機能を提供しています。

---

### 🔨 プロジェクト

開発中のプロジェクト:

- [https://floorp.app](**Floorp ブラウザー**] - ユーザーを第一に考え、プライバシーを尊重する、Firefox ベースのブラウザーです。皆様からいただくフィードバックは次のアップデートに活かされます。
